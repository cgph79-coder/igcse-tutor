# Private reference material

Anything you put in this folder is **ignored by git** and never uploaded to GitHub or bundled into the app.

Use it for your own copies of past papers, mark schemes or notes. Exam-board past papers and mark schemes are copyrighted, so they must never be committed to the repo.

The app does not read this folder yet. See `docs/COMMERCIALISATION.md` ("Reference material") for how it could be wired in later.
